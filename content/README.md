# ~/README.md

You're in a simulated Linux desktop. It's a portfolio, but the shell is real
enough to be worth using.

    $ ls projects/          list the work
    $ cat about.md          who I am
    $ open job-pilot        launch a live demo
    $ neofetch              the usual
    $ help                  everything else

Keyboard, if you want it: `Super + D` opens the launcher, `Super + Enter`
spawns a terminal, `Super + 1..5` switches workspaces. Everything is also
clickable, so none of this requires knowing a tiling window manager.

Prefer a normal resume? `cat resume.pdf` or the link in the status bar.
